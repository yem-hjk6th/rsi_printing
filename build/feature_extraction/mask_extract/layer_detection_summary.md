# Bead Layer Detection — 技术探索总结

## 1. 目标

从 ZED 2i 双目相机录制的 SVO2 视频中，**自动检测 3D 打印 bead 的层数和层界面位置**。

工件：白色塑料圆柱 bead，逐层堆叠（每层高度 ~1mm），相机距离 ~0.45m，俯视侧拍角度。

---

## 2. 方法一：SAM2 自动分割

**工具**：SAM2 (Segment Anything Model 2) hiera_small，自动掩码生成 (AMG)

**流程**：SVO2 → 左目 RGB → ROI 裁切 → SAM2 AMG → 实例 mask + overlay

**结果**：
- SAM2 能把 bead 从背景中分割出来，但它做的是**通用语义分割**
- 无法区分层与层之间的边界——SAM2 把整个 bead 识别为一个或少数几个整体区域
- **不适合层分离任务**

**结论**：SAM2 适合 bead vs 背景分割，不适合层间细粒度检测。

---

## 3. 方法二：2D 纹理分析 (OpenCV)

**工具**：OpenCV + scipy，边缘检测 / 亮度剖面分析

**流程**：
1. HSV 颜色 mask 分离 bead 区域
2. 沿 Y 轴取亮度剖面曲线 → 谷值 = 层间阴影
3. scipy.find_peaks 检测层界面

**结果**：
- 检测到 ~8 层，实际有数十层
- 相机角度（俯视侧拍）导致下层被遮挡，层间阴影不明显
- Bead 表面高光和 nozzle 反射干扰检测

**结论**：相机角度是根本限制。2D 方法在当前视角下精度天花板很低。

---

## 4. 方法三：ZED SDK 深度图

**工具**：ZED SDK (ULTRA/Neural mode)

**流程**：SVO2 → ZED 内置深度 → ROI 内 bead 区域 Z 值直方图 / Y 轴 Z 剖面

**结果**：

| 指标 | 数值 |
|---|---|
| 工作距离 | ~0.45m |
| ZED 深度精度 | ~1-2mm (整数视差) |
| 层高 | ~1mm |
| Z 直方图峰数 | 3.7 avg, max 7 |
| 结论 | **深度噪声 ≈ 层高，无法分辨单层** |

**关键公式**：

$$\Delta Z = \frac{Z^2}{f \cdot B} \cdot \Delta d$$

ZED SDK 整数视差 ($\Delta d = 1\text{px}$)：$\Delta Z \approx 1.6\text{mm}$ ≥ 层高 → 层间信号被噪声淹没

**结论**：ZED SDK 深度精度不足，只能做宏观高度测量（总高 80~210mm），无法数层。

---

## 5. 方法四：Fast-FoundationStereo (FFS) 亚像素深度

**工具**：Fast-FoundationStereo (CVPR 2026)，绕开 ZED SDK 自己做立体匹配

**原理**：
- ZED SDK 只提供左右 rectified 图 + 标定参数 (fx, baseline)
- FFS 做亚像素立体匹配 → disparity (float32, ~0.05px 精度)
- 理论精度：$\Delta Z \approx 0.044\text{mm}$ @0.45m（远优于 ZED）

**结果**：

| 指标 | 数值 |
|---|---|
| Disparity 直方图峰数 | 4.7 avg, max 12 |
| Y 轴阶梯数 | 5.1 avg, max 15 |
| 推理速度 | 0.54s/frame (RTX 5070) |
| Bead 中心匹配成功率 | **低** |

**关键发现**：
- FFS 在 bead **边缘区域**精度远超 ZED SDK，disparity 伪彩可见层纹理
- 但 bead **正面**（白色、无纹理）大面积匹配失败 → disparity = 0
- 这是所有被动双目方法的根本限制：**无纹理表面无法立体匹配**

**结论**：FFS 理论精度够用，但白色 bead 表面缺乏纹理导致实际失效。

## 6. 问题根因总结

```
                    ┌─────────────────────────────────────┐
                    │   白色 bead 无纹理表面               │
                    │   + 相机俯视侧拍角度                 │
                    └──────────┬───────────┬──────────────┘
                               │           │
                    ┌──────────▼──┐  ┌─────▼──────────┐
                    │  2D 方法     │  │  3D 深度方法    │
                    │  (SAM2,     │  │  (ZED SDK,     │
                    │   OpenCV)   │  │   FFS)         │
                    └──────┬──────┘  └──────┬─────────┘
                           │                │
                    被遮挡/阴影不足    无纹理→匹配失败
                           │                │
                    ┌──────▼────────────────▼─────────┐
                    │   均无法可靠检测单层界面          │
                    └─────────────────────────────────┘
```

## 7. 后续优化方向

### 方向 A：主动纹理增强（硬件改动）
- **投影散斑/结构光**：在 bead 表面投射随机纹理图案，解决无纹理匹配失败问题
- 成本低（激光散斑投射器 ~200 元），但需要改造硬件

### 方向 B：RSI Z 坐标解析（无额外硬件）
- KUKA RSI 实时接口已记录每个时刻的 TCP Z 坐标（精度 0.01mm）
- 每次 Z 跳变 = 新层开始
- **纯数据解析**，不依赖视觉，精度最高
- 需要 SVO 帧时间戳与 RSI 时间戳做同步

### 方向 C：更优相机角度
- 正侧面拍摄（而非俯视）→ 层间边界直接可见
- 需要重新设计相机安装位置，可能与机械臂运动区域冲突

### 方向 D：混合方案（推荐）
1. **RSI Z 坐标**提供精确层数和层切换时间 → ground truth
2. **FFS 深度**在 bead 边缘区域验证层高一致性
3. **SAM2** 提供 bead 轮廓 mask，辅助 ROI 自动定位

### 各方向对比

| 方向 | 精度 | 硬件改动 | 实现难度 | 适用场景 |
|---|---|---|---|---|
| A 主动纹理 | 高 | 需要 | 中 | 需要密集深度图时 |
| B RSI Z 解析 | 最高 | 无 | 低 | 只需层数/层时间时 |
| C 相机角度 | 中 | 需要 | 低 | 需要视觉层检测时 |
| D 混合 | 最高 | 无 | 中 | 综合分析时（推荐） |
