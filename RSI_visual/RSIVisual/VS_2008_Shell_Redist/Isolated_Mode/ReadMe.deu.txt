INFODATEI ZUM MICROSOFT VISUAL STUDIO 2008 SHELL REDISTRIBUTABLE PACKAGE (ISOLATIONSMODUS)
===================================================================================

Das VS 2008 Shell Redistributable Package (Isolationsmodus) enthält die folgenden Dateien:

* Readme.txt - diese Datei.
* VS 2008 Shell Redistribution License.txt - die von Ihnen während der Installation des Redistributable Package angenommene Lizenz. Die Datei ist hier zu Referenzzwecken enthalten.
* VS 2008 Shell EULA.rtf - die Software-Lizenzbedingungen, die Sie an die Benutzer des Produkts weitergeben müssen. Details finden Sie in "VS 2008 Shell Redistribution License.txt".

* vs_shell_isolated.exe - das verteilbare Installationsprogramm mit den tatsächlichen Laufzeitbinärdateien von Visual Studio 2008 Shell. Sie können dieses Installationsprogramm zusammen mit der Anwendung entsprechend den in "VS 2008 Shell Redistribution License.txt" angegebenen Bedingungen verteilen. Durch Aufrufen von "vs_shell_isolated.exe /q" können Sie dieses Installationsprogramm in das Setup-Programm der Anwendung aufnehmen. Dieses Installationsprogramm muss in andere Setup-Programme eingebunden werden und ist nicht für die eigenständige Ausführung vorgesehen.

Weitere Informationen zur Verwendung dieses Redistributable Package oder zum Erstellen einer Visual Studio Shell-basierten Anwendung finden Sie unter "http://msdn.com/vsx".
