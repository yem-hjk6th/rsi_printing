MICROSOFT VISUAL STUDIO 2008 SHELL (ISOLATED MODE) REDISTRIBUTABLE PACKAGE README
===================================================================================

The VS 2008 Shell (isolated mode) redistributable package contains the following files:

* Readme.txt - this file.
* VS 2008 Shell Redistribution License.txt - this is the license you accepted during the installation of the redistributable package. The file is included here for your reference.
* VS 2008 Shell EULA.rtf - this is the end user license agreement that you need to pass through to the users of your product. Please refer to "VS 2008 Shell Redistribution License.txt" for details.

* vs_shell_isolated.exe - this is the redistributable installer that contains the actual runtime binaries of the Visual Studio 2008 Shell. You can redistribute this installer with your application under the terms specified in "VS 2008 Shell Redistribution License.txt". You can include this installer your application’s setup program and by calling "vs_shell_isolated.exe /q". This installer is only designed to be chained into other setup programs and is not designed to be run as a standalone installer.

For more information on how to use this redistributable package or on how to create a Visual Studio Shell based application, visit http://msdn.com/vsx.
